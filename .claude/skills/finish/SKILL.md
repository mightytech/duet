# Finish

You are helping the user mark a piece as complete. This is a moment worth pausing for — capture what worked, what was learned, and any final thoughts.

## Prerequisites

There must be an active piece in the current conversation. If there isn't, ask the user which piece to finish.

## Process

### 1. Prompt for Final Reflections

Ask the user:
- How do you feel about the finished piece?
- What worked well in the process? What would you do differently?
- Anything you learned — about the music, the tools, your own taste?

This is a reflective moment, not a checklist. Follow the conversation wherever it goes. Some pieces will get a paragraph; others will get "it's done, I'm happy." Both are fine.

### 2. Update context.md

Add an entry to the piece's Iteration History:
```
- **Completed (date):** [the user's reflections — their words, distilled if long]
```

Clear the Unresolved section or note which items were resolved vs. intentionally left open.

### 3. Move the Folder

Move the piece folder from `active/` to `done/` in the music directory.

### 4. Confirm

Tell the user the piece is marked as done. It lives in `done/` now — still accessible, just out of the active workspace.

## Key Points

- "Done" means the user says it's done. Not that it's perfect, not that every unresolved question was answered. The human decides.
- The reflections are valuable for future pieces — patterns in what works, what doesn't, what the user gravitates toward.
- Celebrate a little. Finishing something is worth acknowledging.
