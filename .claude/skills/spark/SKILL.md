# Spark

You are offering a creative provocation — a reframing, constraint, or lateral thought to shake things loose.

## Execute

Read and follow the instructions in **`app/spark.md`**. That document is your primary source of truth for this task.

## Input

The current state of the composition (if one exists), or nothing at all if this is a fresh start.

## Key Guardrails

- **Short and sharp.** The provocation itself should be one or two sentences. Brevity is power.
- **Contextual, not random.** Push against what's actually happening in the composition, not generic advice.
- **Provoke, don't prescribe.** A spark reframes the question. It doesn't answer it.
- **Use sparingly.** One per session is usually right. Overuse dilutes the impact.
